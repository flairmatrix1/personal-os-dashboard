# Private Personal Dashboard

Локальный персональный дашборд для идей, отраслевых сигналов и рабочих ссылок.

## Локальный запуск

```bash
cd /Users/flairv/personal-os-dashboard
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть: `http://127.0.0.1:8765`

Сервер привязан к локальному интерфейсу Mac. На текущем этапе не меняйте `127.0.0.1` на `0.0.0.0`.

## Данные

- `ideas.json` — идеи видео и постов Portal News.
- `news.json` — проверенные горячие сигналы.
- `channel.json` — реальные результаты опубликованного контента.
- `links.json` — безопасные рабочие ссылки.

## Автоматическое обновление новостей

Workflow `.github/workflows/update-news.yml` запускается каждый час и собирает
свежие материалы из RSS-лент, перечисленных в `news-sources.json`. Скрипт
`scripts/update_news.py` оставляет публикации не старше семи дней, удаляет
дубли, сортирует их по дате и обновляет `news.json`. Если все источники
недоступны, существующий файл не затирается.

Открытая вкладка дашборда перечитывает данные раз в 10 минут и при возврате
фокуса в окно. Workflow также можно запустить вручную на вкладке Actions.

Локальная проверка:

```bash
python3 scripts/update_news.py
python3 -m unittest -v
```

Примеры в `ideas.json` помечены полем `isExample`. Удалите их после добавления своих идей.

Не храните в папке пароли, cookies, ключи, приватные переписки и ссылки с секретными параметрами доступа.

> Важно: опубликованный через GitHub Pages сайт и данные в публичном
> репозитории доступны всем, у кого есть адрес. Для полностью закрытого
> варианта используйте локальный запуск и приватный репозиторий без Pages.
